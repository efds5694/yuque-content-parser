# 语雀内容解析器

一个完全在本机运行的 Edge Manifest V3 扩展，用来把语雀文档转换成更适合复制、归档和提供给 AI 的 Markdown、富文本 HTML 与结构化 JSON。

项目只读取内容：不调用 AI，不修改语雀文档，不读取 Cookie，也不下载图片或附件。一键入口会在点击后向当前语雀站点发起一次同源只读请求，浏览器只自动附带现有登录态；响应不会发送到其他服务。

## 三种读取方式

### 一键解析当前文档

- 在文档右下角点击“析”，保持默认入口，再点击“一键解析当前文档”。
- 扩展从页面已有的 `appData` 获取当前文档路径和知识库 ID，再读取 Lake 源内容并立即解析，无需先下载文件。
- 结果与手动导入 `.lake` 一样标记为“Lake 高保真”。该入口需要当前登录态和文档读取权限。
- 只在点击按钮时访问当前语雀域名；不读取明文 Cookie，不持久化源文件，也不申请 Cookie 权限。

### 当前语雀页面

- 在文档右下角点击“析”打开页内抽屉。
- 支持精确选区和整篇文档。
- 精确选区会保留首尾字符边界以及选区内的链接、加粗等结构。
- 全文模式会滚动扫描语雀虚拟化渲染的正文，并在结束后恢复滚动位置。
- 这种方式只能读取网页已经渲染的信息；高级卡片缺少源码时会显示占位符和解析提示。

### `.lake` 文件

- 在语雀中导出 `.lake` 后，将文件拖入或选择到抽屉中；它也是一键入口不可用时的稳定后备。
- `.lake` 保存的卡片参数比网页 DOM 完整，因此结果会标记为“Lake 高保真”。
- 单个文件上限为 20 MiB。

## 输出格式

- **Markdown**：面向 AI 和普通文本工具，保留标题、列表、任务状态、引用、代码、公式、Mermaid、图片链接和可读的卡片占位。
- **富文本 HTML**：用于富文本粘贴或下载，保留语义标签、合并单元格、折叠区和主要行内样式。
- **JSON**：`schemaVersion: 1` 的规范化 AST，包含来源、保真度、诊断、统计和未知卡片元数据。

简单表格输出为 GFM 表格；合并单元格或嵌套内容使用 Markdown 内嵌的安全 HTML。未知卡片不会被静默丢弃：Markdown/HTML 保留简短占位，详细解码数据进入 JSON。

图片和附件只保留安全的原始 URL。扩展不会请求这些 URL，因此私有 CDN 链接交给外部工具后不一定仍可访问。

## 安装

1. 打开 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目的 `extension` 文件夹。
5. 刷新已经打开的语雀页面。

项目位于 WSL 时，可在 Windows 资源管理器地址栏输入对应路径，例如：

```text
\\wsl.localhost\Ubuntu\home\你的WSL用户名\项目文件夹
```

扩展只申请语雀页面访问、必要的脚本注入和剪贴板写入权限。它不申请 Cookie、调试器、任意网站或下载权限；下载通过浏览器原生文件保存完成。

## 使用

### 一键转换当前文档

1. 打开要转换的语雀文档，点击右下角“析”。
2. 保持“一键解析当前文档”，点击同名按钮。
3. 在 Markdown、富文本和 JSON 之间切换，然后复制或下载。

### 复制当前选区

1. 在语雀正文中选择需要的字符。
2. 点击右下角“析”。
3. 选择“提取网页渲染内容 / 精确选区”，点击“解析当前选区”。
4. 在 Markdown、富文本和 JSON 之间切换，然后复制或下载。

### 转换整篇 `.lake`

1. 在抽屉中选择“导入 .lake 文件”。
2. 选择文件并点击“解析 .lake 文件”。
3. 检查统计和解析提示后复制或下载所需格式。

## JSON 数据结构

```json
{
  "schemaVersion": 1,
  "document": {
    "title": "文档标题",
    "source": {
      "kind": "lake",
      "scope": "document",
      "fidelity": "source",
      "fileName": "example.lake"
    },
    "blocks": []
  },
  "diagnostics": [],
  "stats": {
    "nodes": 0,
    "characters": 0,
    "images": 0,
    "cards": 0,
    "warnings": 0
  }
}
```

块级节点包括段落、标题、列表、引用、提示块、表格、折叠区、代码块、图表、公式、分隔线、嵌入文档、附件、媒体和未知卡片；行内节点包括文本、主要样式、链接、图片、标签、公式和换行。

## 安全与限制

- `.lake` 使用隔离的 `DOMParser` 读取，源文件不会作为可执行页面插入扩展界面。
- HTML 由 AST 重新生成并过滤 URL；脚本、事件属性、`javascript:`、`blob:` 和危险 data URL 不会进入输出。
- 富文本预览使用沙箱 iframe 和阻止外部网络的 CSP，预览图片不会触发 CDN 请求。
- 一键入口依赖语雀网页当前使用的只读文档响应格式；语雀改动站内接口时，可继续使用手动 `.lake` 导入。
- 嵌入抽屉会声明剪贴板写入权限；若语雀页面的 Permissions Policy 仍拒绝 Clipboard API，会自动退回浏览器的同步复制命令。
- 不支持 `.lakebook`、语雀表格/画板文档、知识库批量导出、OCR 或资源本地化。
- 页面模式始终是尽力提取；需要完整卡片源码时请使用 `.lake`。

## 开发与测试

需要 Node.js 20 或更高版本。

```bash
npm install
npm test
```

首次运行端到端测试需准备 Playwright Chromium：

```bash
npx playwright install chromium
npm run test:e2e
```

`npm test` 覆盖 Card 解码、URL 白名单、三种序列化和 Manifest 权限边界；Playwright 覆盖扩展加载、一键 Lake 读取、精确选区、全文扫描、`.lake` 解析、剪贴板降级、预览和下载。

主要目录：

```text
extension/  Edge 扩展、页内抽屉、解析器与序列化器
test/       Node 单元测试
e2e/        Playwright 扩展回归测试与脱敏页面夹具
```
